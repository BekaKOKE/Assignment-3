      How this demo works
      
          
      Two design patterns, one small file manager.
      
        
      
        
      
      

      
      
        
      Protection Proxy: who may do what
      
        
      A guard stands between this page and the file manager. Before every action it looks up your role for that file. Owners can do everything. Viewers can only read. A refused action never reaches the file manager, and the guard writes every decision to the activity panel.
      
        
      Try it: as Beksultan, create a file and share it with Ruslan. Switch to Ruslan, open the file (allowed), then try to delete it (blocked).
      
      
      

      
      
        
      Bridge: swap where files are kept
      
        
      The file manager does not know where bytes are stored. It talks to a storage interface, and you can plug in a different one while the app runs. The top bar lets you choose between Local disk and Database. Your files, owners and sharing stay exactly the same, because only the storage behind the interface changes.
      
        
      Try it: press Database in the top bar, then open any file. The content is still there. The switch appears in the activity panel.
